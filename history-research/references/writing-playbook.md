# 写作手册

目标不是“把所有资料排成一篇”，而是让读者跟着一条清晰的线索，看见一个东西如何变成今天这样。历史长文的说服力来自**证据密度 + 叙事顺序 + 对不确定性的诚实**。

## 基本结构

1. **标题**：具体，不玩虚词。宁可写“京密引水渠与温泉镇的水史”，不要写“水韵悠悠”。
2. **一句话结论**：开头 80–150 字，回答“这段历史最重要的判断是什么”。不要用“让我们走进历史”这类空转。
3. **问题的提出**：为什么现在值得看？一个地名、一条渠、一座建筑、一个机构，或一种今天仍在用的做法。
4. **时间轴**：8–15 个节点，每个节点有年份、事件、依据。时间轴是给读者的地图，不是全文的替代。
5. **主体**：按“层”而不是按“资料类型”分节。常见分法：最早的起点 → 关键转折 → 今天的痕迹。每节回答一个问题。
6. **信史、争议与传说**：把证据强弱显式分开。这是历史写作与旅游文案的分界线。
7. **结语**：回到开头的问题，给出“变”与“不变”的判断，不重复全文。
8. **参考资料 / 图片出处**：文末列来源；图片出处由构建脚本自动生成，但正文图注必须带原始链接。

## 开头

差的开头：

> 在历史的长河中，有这样一条渠……

好的开头：

> 这块河长公示牌上写着“京密引水渠（沙河）流域”。括号里的“沙河”不是一条河，而是温榆河上游的三条沙河；括号外的京密引水渠，则是一条 1960 年代修成、却大体走在 700 年前元代引水线附近的人工渠。

**开头要给一个具体的物/地点/数字，然后立刻揭示它与常识的偏差。** 读者才有继续读的理由。

## 叙事顺序

- **先证据后解释**：先给材料（志书原文、档案日期、地图），再给判断。不要先下结论再找材料。
- **一层一层**：自然地理 → 工程/制度 → 人的活动 → 记忆与争议。不要在同一段里从元代跳到 2023 年。
- **转折点要写“为什么是这个时候”**：水源、战争、人口、技术、决策者，至少给一个可核的原因。
- **把“后来”与“当时”分开**：不要用后来的结果倒推当时的动机。
- **允许插叙，但要有路标**：”要理解这块牌子，得先回到 1292 年。“这类句子是路标。

## 图片

- **密度**：长文每 1500–2500 字至少一张图；3000–8000 字的长文至少 3 张。
- **类型**：历史照片、旧地图、档案扫描、文物/建筑照片、现场照片、数据图表。优先能“作证”的图，不用纯装饰。
- **图注**：谁/什么/哪里/何时/为什么重要。例：
  > 图 3：1937 年落成的辛亥滦州起义纪念园，位于温泉镇显龙山南坡。图源：[北京市文物局](https://...) · 官方页面。
- **来源行**：图片下一行必须是
  ```
  *图源：[原始页面标题](https://...) · 作者/许可*
  ```
  构建脚本会把它渲染成图注和文末“图片出处”表；缺少来源行会直接报错。
- **URL 含括号**：用尖括号包住，例如 `![说明](<https://.../x_(1).png>)`；否则解析器会把它当成未管理图片并拒绝构建。
- **不要热链**：构建时会把图片下载到 `assets/img/`，HTML/PDF 用本地副本；图注保留原始链接。
- **不要**把维基百科缩略图、搜索结果图、Pinterest 图当原始出处；回到文件描述页/机构页。

## 引文与数字

- 每个事实段落至少一个来源链接；关键数字后面紧跟来源。
- 引文用引号，注明出处；长引文单独成段并缩进。
- 数字统一口径：全长/区段长、流域面积/管理面积、开工/竣工/通水。口径不同就在括号里说明。
- 日期统一用“年份（年号）”或“公元年份”，不要混用；不确定就写“约”。
- 人名首次出现给身份，之后用常用称呼；不要用“该人”这种法律文书腔。

## 语言

- 用主动句、短句、具体名词。少用“进行了”“起到了”“具有重要的意义”。
- 一段只做一件事。超过 6 行就拆。
- 避免“首先/其次/最后”的公文结构；用时间、空间或问题推进。
- 允许有判断，但判断要能追溯到证据；不要用“众所周知”“不言而喻”。
- 对争议不要和稀泥：写清楚谁主张什么、依据是什么、你采信哪一边、为什么。

## 长度

- 快读版：1500–2500 字，1–2 张图。
- 标准长文：3000–5000 字，3–5 张图。
- 深度专题：5000–8000 字，5–8 张图；超过 8000 字考虑拆成系列。
- 宁可删掉一段没有新信息的背景，也不要为了长度重复。

## 交付前自检

- [ ] 开头 150 字内出现具体对象和核心判断。
- [ ] 时间轴每个节点有依据，日期不打架。
- [ ] 每个二级标题下至少一个来源链接。
- [ ] 标准长文至少 3 张图（快读版 1–2 张），每张有原始页面链接和许可/作者说明。
- [ ] “信史 / 争议 / 传说”三者没有混写。
- [ ] 规划稿、征求意见稿没有被写成已实施。
- [ ] 结尾回答了开头的问题，没有引入新事实。
- [ ] 全文没有“自古以来”“众所周知”这类无证据的顺滑句。
